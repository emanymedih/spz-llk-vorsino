# Программа комплексных испытаний СПЗ, ЛЛК-Интернешнл, Ворсино

Программа комплексных испытаний систем противопожарной защиты завода по производству, хранению и отгрузке смазочных материалов (филиал ООО «ЛЛК-Интернешнл», с. Ворсино, владение 8) с учётом СТУ.

Текущая редакция документа: **ред. 9 от 15.10.2026**, рабочая версия от 18.10.2026. Мастер-DOCX последний раз изменён в коммите `e5e2ee7497ebc4403a2c77c03b257c24c5008e71`.

## Итоговый аудит 18.10.2026

Основные документы после полной повторной проверки:

- `docs/итоговый_аудит_всех_файлов_18_10.md` — основной сводный аудит текущего master DOCX, 17 PDF, шести отчётов Claude и остальных файлов репозитория;
- `docs/реестр_источников_итог_18_10.md` — SHA-256, страницы, дубли и иерархия исходников;
- `docs/нерешенные_вопросы_18_10.md` — актуальный список блокирующих и открытых вопросов.

Документы `docs/жесткий_аудит_проверки_Claude_18_10.md` и `docs/ревью_проверки_Claude_18_10.md` сохраняются как история промежуточных проверок. При расхождении статусов приоритет имеет итоговый аудит.

Главные открытые темы: применимая редакция СТУ и происхождение п. 2.3.2, фактический объём и водный баланс пожарных резервуаров, рабочая точка повысительной станции 0943, исполнительная конфигурация систем.

> С 16.10.2026 мастер-файл находится в `output/`. Папка `src/` отражает ред. 9 до ручных правок заказчика и последующих редакций. Пересборка из `src/` потеряет изменения master DOCX и может вернуть уже исправленные технические формулировки.

## Состав

| Папка | Что внутри |
|---|---|
| `output/` | Текущий master DOCX. Предыдущие редакции доступны в истории коммитов. |
| `src/` | Историческая генераторная база на JavaScript. Использовать только для анализа и вёрстки после ручного переноса актуальных правок. |
| `docs/` | Аналитика, тематические сверки, итоговый аудит, реестр источников и открытые вопросы. |

## Сборка

```
npm install
npm run build
```

Команда перезаписывает `output/Программа_комплексных_испытаний_СПЗ_ЛЛК_Ворсино.docx`. Перед запуском требуется перенести в `src/` все изменения master DOCX, иначе часть актуальной редакции будет утрачена.

## Исходные данные

PDF и СТУ в репозиторий не включены. Их текущая идентичность и дедупликация зафиксированы в `docs/реестр_источников_итог_18_10.md`.

Для инженерных выводов применять следующую иерархию: фактическое исполнение и исполнительная документация, рабочая документация актуальной ревизии, применимые СТУ/изменения и расчёт риска, стадия П, техническая документация изготовителя, расчётные предположения.
