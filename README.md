# Программа комплексных испытаний СПЗ, ЛЛК-Интернешнл, Ворсино

Программа комплексных испытаний систем противопожарной защиты завода по производству, хранению и отгрузке смазочных материалов (филиал ООО «ЛЛК-Интернешнл», с. Ворсино, владение 8) с учётом СТУ 2016 г.

Текущая редакция: **ред. 9 от 15.10.2026**, рабочая версия от 16.10.2026 (на базе правок заказчика, версия 4).

> С 16.10.2026 мастер-файл это docx в `output/`, правки вносятся в нём. Папка `src/` отражает ред. 9 до правок заказчика и больше не источник истины: пересборка из неё потеряет ручные правки.

## Состав

| Папка | Что внутри |
|---|---|
| `output/` | Программа в docx. Предыдущие редакции (ред. 2–8) лежат в истории коммитов. |
| `src/` | Исходники: Программа собирается из JavaScript библиотекой [docx](https://www.npmjs.com/package/docx). |
| `docs/` | Рабочие материалы: разбор СТУ, рецензия черновика от 14.10, сверка с НТД, анализ проектной документации, запрос недостающих данных. |

## Сборка

```
npm install
npm run build
```

Результат перезаписывает `output/Программа_комплексных_испытаний_СПЗ_ЛЛК_Ворсино.docx`. Места, которые заполняются по недостающим данным, помечены `[[…]]` и выделены в документе жёлтым.

## Где что править

| Файл | Разделы |
|---|---|
| `src/build.js` | Титул, сборка документа, приложения А, Б, В, Г, Д, И, К |
| `src/content1.js` | Разделы 1–5: область применения, ссылки, сокращения, исходные данные, состав систем |
| `src/content2.js` | Разделы 6–10: организация, критерии, методики СПС, СОУЭ, пожаротушения |
| `src/content3.js` | Разделы 11–17: ВПВ, противодымная вентиляция, компенсирующие мероприятия, сценарии, огнезащита, ОПР, оформление |
| `src/forms.js` | Приложения Е и Ж: формы и образцы актов |
| `src/lib.js` | Стили и общие функции вёрстки |

## Исходные данные

Проектная документация (PDF, около 140 МБ) и СТУ в репозиторий не входят. Перечень полученного и недостающего: `docs/анализ_ПД_недостающие_данные_15_10.md` и приложение И Программы.

Ждём данные по запросу от 15.10.2026 (`docs/запрос_недостающих_данных_15_10.md`). После их получения заполняются поля `[[…]]`.
